IDeaL: Data-Free Multi-Teacher Distillation via Improved Dead Leaves

Feyza Yavuz, Mert Bülent Sarıyıldız, Diane Larlus

NAVER LABS Europe

Paper arXiv Code BibTeX

Abstract

Multi-teacher distillation merges complementary vision models — supervised and self-supervised — into one student that inherits the strengths of all of them. But every existing method assumes the teachers can be fed real images, usually their own training data. What if that data is private, proprietary, or simply gone?

We take the adversarial stance: we distill four ImageNet-trained ViT-B/16 teachers into a student without a single real image. Starting from procedural Dead Leaves noise, we treat the pixels as learnable parameters and optimize them through the frozen teachers with two decorrelation losses — within each image and across the batch — producing IDeaL, a reusable data-free distillation set. With 1M IDeaL samples the student reaches 78.2 ImageNet Top-1 (vs 66.9 for plain Dead Leaves) and clears its own weakest teacher on transfer, segmentation, and depth.

The method

Two losses, one idea: decorrelate

ViT attention thrives on diversity. So we treat pixels as parameters and push representations apart — inside each image, and across the batch.

The same four teachers supervise twice: first they shape the pixels (Step 1), then they teach the student (Step 2).

Step 1 — generate

Optimize the noise

Start from Dead Leaves. Backpropagate two decorrelation losses (plus a total-variation regularizer) through the frozen teachers, updating only the pixels. No labels, no classification heads, no teacher training data.

Step 2 — distill

Train the student

Use the optimized images exactly as if they were real data, in an unmodified UNIC multi-teacher distillation setup. Generation cost is paid once; the dataset is reusable for any student.

Patch decorrelation LPD

Within one image, make every patch carry distinct information: drive the off-diagonal of the patch-similarity matrix Γ to zero, at every layer of every teacher.
